several projects. Each is MIT licensed; the copyright lines and the

**Vendored file:** `base-theme.css` is dracula-for-stash's
`dracula-theme.css` (v1.3.11) with the changes listed in its own header
comment — the whole-app Dracula palette for stash, every color as a CSS
